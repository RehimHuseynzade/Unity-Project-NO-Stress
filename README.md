## 🎮 About the Game

**NO STRESS!** is a Unity-based game focused on entertainment, engaging gameplay, and a colorful visual experience.

Featuring vibrant neon graphics, lively music, and progressively challenging gameplay, NO STRESS! offers players an enjoyable experience where timing, progression, and rewards keep the action going.

The objective is simple: pass enemies, earn points, and progress through increasingly challenging stages of the game.

## ✨ Features

- **Neon Visuals:** Colorful graphics and visual effects.
- **Dynamic Gameplay:** Pass enemies to earn points.
- **Progression System:** Your score determines your progress.
- **Multiple Enemy Types:** Encounter different enemies as you advance.
- **Increasing Difficulty:** Gameplay becomes more challenging over time.
- **Reward System:** Different enemies provide different point rewards and progression opportunities.
- **Music & Audio:** Lively music that complements the gameplay.
- **Mobile Experience:** Designed with a portrait-oriented mobile gameplay experience in mind.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Unity Hub
- A compatible Unity Editor version
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/RehimHuseynzade/Unity-Project-NO-Stress.git
   ```

2. Open Unity Hub.

3. Select **Add Project from Disk**.

4. Navigate to the cloned project directory.

5. Open the project using the appropriate Unity Editor version.

6. Open the main game scene and press **Play**.

## 🎯 Gameplay

The gameplay revolves around passing enemies and collecting points.

As the player's score increases:

- New enemy types become available.
- Different enemies offer different point rewards.
- Progression becomes more challenging.
- Players have new opportunities to increase their score.

The goal is to keep progressing and achieve higher scores.
